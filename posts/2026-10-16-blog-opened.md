개발하며 배운 내용을 기록하려고 블로그를 열었습니다. 포트폴리오와는 별도 저장소에서 빌드하고 배포하며, 주소는 같은 도메인의 `/blog/`를 씁니다.

## 구조

- 사이트는 [Astro](https://astro.build/)로 만든 정적 사이트이고, GitHub Pages에 배포합니다.
- 글은 저장소의 `posts/` 폴더에 마크다운 파일로 씁니다. 이미지는 글과 같은 폴더의 `images/`에 둡니다.
- `main` 브랜치에 push하면 GitHub Actions가 빌드하고 자동으로 배포합니다.

## 글 하나의 형태

글 맨 위에 제목, 날짜, 요약을 적습니다. 셋 중 하나라도 빠지면 빌드가 실패해서, 형식이 틀린 글이 공개되지 않습니다.

```yaml
---
title: 글 제목
date: 2026-10-16
description: 한두 문장 요약
tags: [astro]
---
```

주소는 파일명에서 날짜를 뺀 부분으로 정해집니다. 이 글의 파일명은 `2026-10-16-blog-opened.md`이고, 주소는 `/blog/blog-opened/`입니다.
